Individual Project

Introduction: My project, Lost Signal, is a short interactive game developed using JavaScript and the p5.js library in Vscode. The game is set in a dark, fictional, town where the player must collect missing "clues", while avoiding a shadow-like creature. The narrative is minimal, but atmospheric as it focuses mystery, tension, and survival. Furthermore, the player must navigate their environment by using the keyboards arrow controls, collecting four clues, and unlocking a portal to escape. As the game progresses, the obstacles increase through staged gameplay, eventually introducing a shadow monster. The aim of the project was to create an engaging interactive experience using simple mechanics to demonstrate an understanding of core programming concepts such as state management, collision detection, and user interaction. 

Technical Approach, Inspiration, and Reflection: The game is structured by a state-based system controlled by the 'gameState' variable, which manages the shift transitions between the start, play, win, lose, screens, allowing for a clear and organised game flow.
