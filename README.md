Individual Project

Introduction:
My project, Lost Signal, is a short interactive game developed using JavaScript and the p5.js library in Vscode. The game is set in a dark, fictional, town where the player must collect missing "clues", while avoiding a shadow-like creature. The narrative is minimal, but atmospheric as it focuses mystery, tension, and survival. Furthermore, the player must navigate their environment by using the keyboards arrow controls, collecting four clues, and unlocking a portal to escape. As the game progresses, the obstacles increase through staged gameplay, eventually introducing a shadow monster. The aim of the project was to create an engaging interactive experience using simple mechanics to demonstrate an understanding of core programming concepts such as state management, collision detection, and user interaction. 

Technical Approach, Inspiration, and Reflection: 
The project is based on a state based system, where the gameState variable, allows for transition between the start, play, win and lose screens, creating a clear and manageable flow of interaction. The core gameplay takes place on an infinite draw loop that updates player movement, environment rendering , and interactions in real time for a responsive experience . The player movement is managed using keyIsDown() for smooth control in any direction, and boundaries are set to keep the player within the canvas. The dist() function is used for collision detection. It determines whether the player can interact with the clues, lose lives when touching the monster, and trigger the win condition when the player reaches the portal. The technical structure is further supported by a stage-based progression system, related to the player’s score. This functions not only as a gameplay mechanic but also as a means of structuring tension. The first stages of the game encourage discovery, but later stages add a sense of urgency to activating both the monster and the portal, shifting the player’s objective from exploration to survival. A direct tracking algorithm is used to move the monster towards the position of the player, intentionally keeping the behaviour simple. This approach turns out to be effective in producing sustained pressure without over complicating the code. Furthermore, The project is made visually of basic shapes, rectangles, ellipses and triangles, showing how atmosphere can be created with colour, layering and transparency rather than external assets. The supernatural tone is supported by subtle animated elements such as the pulsing portal, and the heads-up display provides important feedback on score, lives and stage to aid player awareness and progression. The project is conceptually inspired by Stranger Things and its fusion of small town setting, supernatural threat, and narrative of disappearance and search. But these influences are filtered through an original framework avoiding direct reproduction, and concentrating on mood and structure. For me personally, retro arcade games and early 2D design provide additional inspiration, where simple mechanics and clear objectives drive engagement, reinforcing the project's emphasis on accessibility and playability. The development process was successful in creating a coherent and functional game system, especially through the effective integration of state management and staged progression, in terms of collaboration. Meanwhile, coordinating multiple conditional systems, such as correctly triggering the monster, portal, and life mechanics without breaking the flow of the game, proved to be a challenge. Collision detection also had to be refined to ensure interactions felt consistent and fair. These issues were solved by iterative testing and dividing the code into smaller, manageable parts, which enabled each feature to be implemented and tested independently prior to integration. Collaboration is a key aspect in this process, as it allowed to discuss problems and to improve solutions, thus leading to a more structured and reliable final result. Overall, the project shows a good balance of technical control and creative design, and shows a good beginner level understanding of interactive media development.
